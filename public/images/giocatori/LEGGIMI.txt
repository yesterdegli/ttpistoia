Foto giocatori — pagina /giocatori
==================================

Cartella di consegna:
  public/images/giocatori/

Nome file (senza spazi):
  nome_cognome.<estensione>

Esempi:
  luca_pancani.webp   (va bene anche Luca_Pancani.png)
  chiara_dabizzi.jpg
  alessandro_guarino_lo_bianco.webp   (nome = ultima parola in scheda)

Formato consigliato: .webp (trasparenza). Accettati anche .png .jpg

Nuove foto PNG: npm run convert-giocatori-webp (qualità 98, elimina i PNG).

Alone bianco sui capelli dopo lo scontorno:
  npm run defringe-giocatori              (anteprima in _defringe-preview/)
  npm run defringe-giocatori -- --apply   (sovrascrive WebP, backup in .backup-defringe/)
  Il risultato migliore resta uno scontorno rifatto dal file originale (Photoshop / remove.bg).

In scheda il testo può essere "Nome Cognome" o "Cognome Nome":
il sito prova entrambi gli ordini (es. Pancani Luca → luca_pancani).

Se il nome non combacia, rinomina il file o chiedi di aggiungere
un override in lib/content/giocatori.ts.

Dopo aver copiato i file: commit/push e ricarica /giocatori (Ctrl+F5).
